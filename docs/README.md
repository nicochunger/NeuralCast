# Docs Layout

`docs/` contains active project documentation that is useful for current workflows.

- `docs/repo_cleanup_inventory.md`: cleanup classification and artifact policy notes.
- [NeuralCast playlist definitions](../NeuralCast/playlist_descriptions.md) and
  [NeuralForge playlist definitions](../NeuralForge/playlist_descriptions.md):
  current playlist intent, placement boundaries, and intentional overlap policy.
- `docs/host_channels.md`: multilingual host channels, inheritable archetype
  policies, per-channel topic/country overrides, and test workflow.
- [Editorial feature ideas](editorial_feature_ideas.md): proposed release-retention
  checks, a host companion, and the historical radio episode concept.
- [Private music discovery](music_discovery.md): five-song auditions, admin feedback,
  accepted-only catalog promotion, and weekly/manual generation.
- [Manual podcast episodes](episode_producer.md): podcast introductions, proposal
  approvals, production, preview uploads, website publication, and Episode guides.
- [Listener host companion](host_companion.md): summary cards, generation,
  publication timing, and web integration.
- [Release editorial retention](release_editorial.md): automatic Codex review of
  aging releases, the discard budget, runtime requirements, and retry behavior.
- `docs/tts_model_experiment_2026-08-29.md`: TTS provider comparison, Argentine-accent results, costs, and decision record.
- `docs/archive/`: historical design notes, prompt archives, and superseded docs retained for reference.

Repository root keeps only the primary onboarding docs (`README.md` and
`AGENTS.md`) plus runnable shims and data folders.

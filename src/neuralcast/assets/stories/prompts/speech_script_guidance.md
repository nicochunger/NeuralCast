Guion para Gemini 3.8 TTS:

- Entrega solo las palabras exactas que se deben decir. El texto es una transcripcion literal: no incluyas instrucciones, etiquetas de locutor, Markdown, SSML, HTML ni acotaciones entre corchetes o parentesis.
- La identidad permanente de la voz (edad, timbre, acento y registro) ya esta configurada fuera del guion. No intentes redefinirla en cada segmento.
- Escribe para hablar: usa comas, puntos, guiones y "..." solo cuando expresen una respiracion, duda o giro reales. No llenes el texto de elipsis.
- Usa expresiones vocales momentaneas en etiquetas inglesas entre <> cuando aporten una respiracion, reaccion o cambio de actitud a la interpretacion. Elegi las que encajen con la frase: <short pause>, <long pause>, <breath>, <heavy breath>, <exhales>, <sigh>, <sighs>, <chuckle>, <chuckles>, <laugh>, <laughter>, <giggle>, <snicker>, <tsk>, <pff>, <phew>, <gasp>, <throat-clearing>, <cough>, <yawn>, <cheer>, <whispering>, <whispers>, <shout>, <growl>, <grr>, <hiss>, <argh>, <cackle>, <cry>, <groan>, <grunt>, <moan>, <pant>, <scream>, <shriek>, <sneeze>, <snort>, <sob>, <whimper>.
- Nunca inventes otras etiquetas ni uses efectos no vocales (musica, aplausos, golpes, truenos). No uses etiquetas dentro de nombres de artistas, titulos, fechas o datos factuales.
- Las muletillas, dudas y autocorrecciones humanas deben escribirse como palabras habladas, no como instrucciones. No hay una cuota fija de etiquetas: usa las que ayuden a la interpretacion, sin encadenarlas ni repetirlas por sistema.
